# C1-E4o: какой G-auto ставить в C1-E4 — итог офлайн-проверки

*Aleksandr Karpov · 2026-10-03 · Мак, 21 с · Дизайн и правило выбора запушены до расчёта: [спек](../superpowers/specs/2026-10-03-c1-e4o-gauto-offline-design.md) (504f0aa), код e714366 · Числа — `results/c1-e4/gauto_offline.json`*

## Итог: выбранный вариант G-auto

- **Закон передачи З1.** С новым планом N рефлекс считает долю κ_N = s_N + κ̄·(1 − s_N).
  - s_N — доля сдвига, которую рука уже унесла рефлексом к наблюдению плана. Рефлекс знает её точно.
  - κ̄ — выученная доля самого мозга.
  - Дальше передача как у семейства G: U(t) = (1 − κ_N)·Δ_N + (p(t) − p(t_obs_N)).
- **Оценка κ̄ — бегущая медиана.**
- **Источник образцов — теневой парный вызов** в момент включения рефлекса.
  - Мозг вызывается дважды с одним шумом: на сохранённом наблюдении до сдвига и на текущем.
  - Образец = `target_diff`·u/|Δ|. Оба плана выбрасываются, расписание не трогается, +2 вызова на сдвиг.
- **Без корзин** «близко / далеко».
- **N = 30 сдвигов** — калибровка до заморозки κ̄ для правила C1-E4. Калибровочные сдвиги идут по кругу задач.

## Что ещё видно (только отчёт)

- **Доля, которую план переносит из унесённого рукой.** На α = 0 сырая доля при s ≈ 0 / 0.2 / 0.74 / 1.0 — −0.02 / 0.20 / 0.58 / 0.96, то есть почти ровно s.
  - Поправка «ĉ < 1» не окупилась: З2 лучше З1 всего на 0.01.
  - Значит, планы SmolVLA несут смещение руки целиком, а G-keep (κ = 0) неправ всегда, когда рука уже унесла сдвиг.
- **Сравнение законов на всех планах после включения** (медиана \|κ_N − r\|, другая половина задач):

  | α | З1 | G (κ ≡ 1) | G-keep (κ ≡ 0) | G-R (ориентир: читает свой план) |
  |---|---|---|---|---|
  | 0 | **0.40** | 0.62 | 0.73 | 0.46 |
  | 0.5 | **0.31** | 0.45 | 0.71 | 0.50 |
  | 1 | **0.38** | 0.41 | 0.96 | 0.49 |

  З1 точнее G, G-keep и даже G-R, который видит каждый план, но тонет в дрожании (мёртвая зона C1-E3). По последнему плану эпизода — та же картина.
- **Онлайн-образцы шумные:** у SmolVLA (α = 0, s ≤ 0.1) медианой нужно 73 образца до ±0.10, у π0.5 по парному вызову — 27. Поэтому источник «исполняемые планы» не годится и по шуму, а не только по редкости.
- **Синтетический α-мозг:** при α = 1 доля по чистым планам 0.91 против «истины» 1.04 (добавка α обрезается, как и предполагалось). При α = 0.5 медиана с равным весом задач 0.54, а по всем образцам 0.45: задачи сильно различаются.
- **Подстройка по промаху не годится.** Эффективная постоянная доля κ* (по парам G / G-keep) — 0.70 / 0.86 / 1.04 при α = 0 / 0.5 / 1, но межквартильный размах от 0.0 до 1.2–1.7. Знаковая подстройка не сходится к ±0.10 за 300 сдвигов ни в одной ячейке.
- **Медиана π0.5 по задачам** колеблется от 0.09 до 0.63. Корзины по задаче при N = 30 не набрать (≈ 1 образец на задачу).

## Что это значит для C1-E4

- **G-auto = З1 + медиана + теневой парный вызов + N = 30**, калибровка по кругу задач, затем κ̄ заморожена на оценочных эпизодах. G-κ₀ — тот же закон с κ̄ = κ₀ (π0.5 0.355, SmolVLA 0.038).
- **Цена — +2 вызова мозга на сдвиг.** В отчёт и в правило: сравнение G-auto с G и G-keep честно по успеху, но не по числу вызовов.
- **На SmolVLA З1 ≈ «G для поздних планов, G-keep для ранних».** Ровно этого не хватало G в C1-E2: он терял сдвиг, когда план после сдвига приходил в первые 5 шагов.

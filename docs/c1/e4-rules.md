## Как читать

- **Одна таблица на этап.** Столбцы:
  - **правило** — имя из спека;
  - **формулировка** — условие, как записано, коротко;
  - **записано** — раздел спека, коммит и дата, где правило появилось в этой форме;
  - **прочитано** — оценка и 95% [lo; hi]; односторонняя граница — если правило её использует;
  - **итог** — как в записке;
  - **данные** — файл и коммит, который первым добавил его в git.
- **Разности** — успех в п.п., парно; 95% — бутстрэп с кластерами по исходной задаче (26 на стенде, 33 в LIBERO-MAX). Жирным — разность, у которой 95% интервал без нуля.
- **Виды итога:**
  - **прошло / не прошло** — правило с порогом;
  - **чтение по правилу** — правило с несколькими исходами, без «прошло»: исход назван словами, записанными до данных;
  - **измерение** — оценка и интервал без порога. Слов «лучше» и «не хуже» оно не даёт;
  - **измерение с границей** — заранее заявленная фраза по односторонней границе, не вердикт;
  - **снято до чтения** — правило убрано до того, как прочитаны его данные; числа нет;
  - **метод записан постфактум** — число посчитано раньше, чем записан метод;
  - **процедура** — правило выбора (режим, k, λ, зона), а не проверка метода;
  - **проверка** — условие до чтения; при провале правила не читаются.
- **Каждое правило — отдельное утверждение.** Поправки на множественность нет ни в одном спеке: часть 1 §8, часть 2 §9, контрольный §8, плацебо §6 («правило одно»).
- **«Записано до данных»** проверено по git: коммит спека раньше коммита, который первым добавил файл данных. У всех строк так и есть. Где git этого не доказывает или правило записано после того, как данные уже существовали, стоит пометка [п. N] — см. «Пометки» в конце.

# C1-E1: офлайн kill-тест рефлекса на SmolVLA в LIBERO — записка

*Aleksandr Karpov · 2026-09-28 · Правила §5 записаны до данных ([спек](../superpowers/specs/2026-09-27-c1-e1-offline-design.md), журнал изменений) · Данные: `results/c1-e1/` (`e1.jsonl`, `summary.json`) · Mac M1 Max, MPS, fp32; политика `HuggingFaceVLA/smolvla_libero`; 4 набора × задачи 0–7 × 8 состояний = 256 состояний · Разведочный kill-тест, не вердикт статьи*

**Как читать числа:**
- **R** — доля сдвига, которую свежий вызов политики убирает (рука) или за которой идёт (предмет) за первые H действий плана; 1 — всю, 0 — не замечает.
- **ρ** — доля изменения первого действия при свежем вызове, которую восстанавливает поправка (форма E1b, исполняемые действия, поправка обрезана ±1). 1 — поправка = свежий вызов, 0 — не лучше старого плана, < 0 — хуже старого плана.
- **Медианы** — по пулу (состояние × направление × знак сдвига). Интервалы — бутстрэп с кластеризацией по задаче (32 роллаута целиком), только в отчёт.
- **Три кандидата:**
  - `J_s` — точный якобиан по числам руки;
  - `J_vis`-рука — касательная по конечной разности при ±2 мм с перерисовкой сцены (оракул);
  - `J_vis`-предмет — то же для сдвига предмета.

## Итог

**Вердикт по §5: KILL.** Ни один вариант `J`-рефлекса не прошёл. Запас руки слабый, запаса предмета нет.

| правило (§5) | вердикт | медиана | наборы, где прошло | 95% интервал |
|---|---|---|---|---|
| Запас руки: R за 10 шагов, сдвиг 1–2 см | **СЛАБЫЙ** | 0.090 | — | 0.077…0.111 |
| Запас предмета: то же | **НЕТ ЗАПАСА** | 0.014 | — | 0.007…0.021 |
| GO-state: ρ `J_s` при 1 см ≥ 0.3, знак ≥ 0.6 | **не прошло** | 0.127, знак 0.76 | 0 из 4 (S 0.18, O 0.12, G 0.15, 10: 0.08) | 0.093…0.162 |
| GO-vis-arm: ρ `J_vis`-рука при 1 см ≥ 0.3 | **не прошло** | −0.51 | 0 из 4 | −0.61…−0.40 |
| GO-obj: ρ `J_vis`-предмет при 1 см ≥ 0.3 | **не прошло** | −0.91 | 0 из 4 | −1.10…−0.77 |

- **Политика сама почти не реагирует на сдвиги внутри чанка.**
  - Смещение руки свежий план за 0.5 с убирает на 9%, за 25 шагов — на 29%, за весь чанк (2.5 с) — на 51%.
  - За сдвинутым предметом план не идёт даже за весь чанк: 1.4 / 2.8 / 4.5% за 10 / 25 / 50 шагов.

  Рефлекс, подражающий политике, не может быть отзывчивее её самой. Для предмета подражать нечему.
- **`J` по числам руки видит малую часть отклика.** ρ = 0.13 при 1 см, хотя знак верен в 76% случаев. Причина та же, что в разведке: в 59–85% состояний отклик идёт через картинку.
- **Визуальная касательная хуже, чем ничего.** Сдвиг на ±2 мм — это меньше пикселя, и отклик на таком шаге — шум дискретизации рендера. Даже при 1 мм остаток касательной 0.95, а на 1–2 см она уводит поправку в сторону (ρ < 0).
- **Цена:** точный `J_s` — 4.0 вызова на позицию (MPS), конечная разность по двум направлениям — 2–4 вызова. Удешевления нет.

## Проверки перед чтением и отступление

- **Прогон полный:** 32 роллаута, 256 состояний, по 8 на задачу. Отказов обратной кинематики — 45 из 6144 сдвигов руки (0.7%). Сдвигов предмета без отклика — 35. Две задачи без подвижного предмета: Goal 0 (ящик) и Goal 7 (плита).
- **Проверка перед чтением не пройдена:** 16 успешных из 32 при пороге 20.
  - Разбор настройки штатным `lerobot-eval` на тех же задачах: 21 из 32 на тех же начальных состояниях; 38 из 64 (59%) на начальных состояниях 0–1; 22 из 32 (69%) по протоколу лидерборда (`n_action_steps = 1`).
  - Разница 16 против 21 — около 1.3σ для независимых выборок и около 1.4σ по Макнемару для пар (9 несовпадений против 4), в пределах шума.
  - Настройка исправна; порог был оптимистичен: рассчитан на ~73%, а на этом Маке — ~59%.
- **Отступление.** Владелец выбрал читать данные (вариант (А)). Отступление записано и запушено до чтения (`23a7a68`); правила §5 применены без изменений.
- **Две правки кода по сбоям посреди прогона, обе до чтения:**
  - `cf79159` — Goal 0 упала: её предмет интереса — область шкафа без свободного сустава. Теперь сдвигается первый подвижный предмет из `obj_of_interest`; если такого нет, сдвигов предмета нет, а стадия считается до сайта области.
  - `4f53871` — Goal 7 упала: первый предмет интереса — неподвижная плита без сайта с её именем. Стадия считается до её `_default_site`.
  - Обе правки меняют только задачи без подвижного предмета; 16 уже посчитанных задач Spatial и Object не затронуты. Goal 0, Goal 1 (прервана при остановке) и Goal 7 пересчитаны тем же кодом.

**Фаза** — доля состояний, где полный отклик на сдвиг руки на 1–2 см ближе к отклику «только картинка», чем к отклику «только состояние»:

| разбивка | доли |

| стадии | далеко 59% (n = 1005), близко 81% (232), схват закрыт 77% (796) |
| трети эпизода | 50% / 85% / 71% |

Состояний по стадиям: далеко 127, близко 29, закрыто 100.

**Линейность** — остаток ‖истинный отклик − поправка‖ / ‖истинный отклик‖ на первом действии:

| поправка | 1 мм | 5 мм | 1 см | 2 см |
|---|---|---|---|---|
| `J_s` (рука) | 1.00 | 0.94 | 0.88 | 0.77 |
| `J_vis` (рука) | 0.95 | 1.17 | 1.54 | 1.90 |
| `J_vis` (предмет) | 0.96 | 1.19 | 1.91 | 2.93 |

**Знак** (доли; «возвращающий» для руки, «следующий» для предмета):
- Истинный отклик первого действия на сдвиг руки возвращающий в 51 / 57 / 61 / 64% при 1 / 5 / 10 / 20 мм.
- Поправка `J_s` возвращающая в 64% и совпадает с истинным откликом по знаку в 57 / 70 / 76 / 81%.
- `J_vis`-рука: возвращающая в 56%, совпадает в 67–72%.
- Предмет: истинный отклик следующий в 50–60%, касательная — в 52%.

**ρ при 2 см:** `J_s` 0.23, `J_vis`-рука −0.82, `J_vis`-предмет −1.87.

**Цена** (MPS, fp32, медиана по состояниям):
- вызов 457 мс;
- `J_s` одной пачкой VJP — 1835 мс, то есть 4.0 вызова на позицию;
- перерисовка 10 мс;
- `J_vis` по двум направлениям — 2.0 вызова односторонней разностью или 4.1 центральной;
- aten-операций: `J_s` 201 тыс., вызов 38.5 тыс.

| P2: ρ_s < ρ_vis | **не сбылось:** 0.13 против −0.51, визуальная касательная хуже |

**Постфактум, не правило.** Хорда по ±1 см вместо касательной по ±2 мм предсказывает отклик на 2 см с медианой ρ 0.28 для руки и ≈ 0 для предмета. Грубая «визуальная хорда» для руки почти у порога. Но она найдена после чтения, считается только через перерисовку сцены (оракул) и не спасает предмет, у которого нет запаса.

## Что это значит для C1

1. **Бесплатный `J`-рефлекс на SmolVLA в LIBERO в проверенных формах закрыт.** Это касается числового `J` руки и визуальной касательной для руки и предмета. GPU-этап по черновику плана не нужен.
2. **Главная причина — не качество `J`, а сама политика.** Внутри чанка она мало реагирует на отклонения: рука — 9% за 0.5 с, предмет — почти ноль даже за весь чанк. На подходе она видит руку на картинке. В Kinetix у политики был запас, и `J` его забирал; здесь забирать почти нечего.
3. **Что остаётся открытым** (идеи, не утверждения):
   - запас руки на масштабе всего чанка (R₅₀ ≈ 0.5) — поправка на масштабе чанка, а не пошаговая линеаризация;
   - методы со стороны картинки (как у FutureRTC) — с обучением;
   - distill — с обучением.
4. **Базовую успешность SmolVLA мерить на поде**, до любых выводов по C1 на GPU. На Маке протокол лидерборда даёт 69% вместо 87%. Возможно, дело в MPS или версиях, так что все числа этой записки — Mac, MPS, fp32.
5. **Ограничения.**
   - Две задачи из 32 без подвижного предмета.
   - Визуальные `J` — оракул перерисовки.
   - Выборка состояний — из роллаутов с успехом 50%, против 66% у штатного инструмента на тех же начальных состояниях; разница в пределах шума.

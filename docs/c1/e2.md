**Как читать числа:**
- **Разности** — успех в п.п., парно по seed'у эпизода, в пуле. В скобках — 95% бутстрэп с кластеризацией по задаче (26 кластеров); «одност.» — нижняя граница односторонних 95%.
- **Ячейки (s, d):** A (10, 0), B (25, 0), C (50, 0), D (20, 10), E (40, 10), F (25, 20), G′ (30, 20). s — через сколько шагов плановый вызов, d — задержка ответа мозга (20 Гц: d = 20 ≈ 1 с).
- **Методы:**
  - **нет** — без рефлекса;
  - **T₀** — внеплановый вызов мозга при сдвиге ≥ 1 см;
  - **G** — геометрический рефлекс: остаток плана сдвигается вслед за предметом;
  - **G + T** — G плюс внеплановый вызов при сдвиге > 5 см;
  - **PPC** — наша реализация PPC.
- **Классы величины сдвига:** 1–2 / 3–4 / 5–6 см.

## 2. Почему R3 не прошёл

R3: C-(G + T) − A-нет = −13.3 [−18.8; −7.8], одност. −18.0 при пороге −5. **Не прошло.** Ниже разбор, только в отчёт.

**(а) Редкий мозг дорог сам по себе.** Слагаемые на начальных состояниях 0–9:

| сравнение | разность | 95% |
|---|---|---|
| контроль (без сдвига): C-нет − A-нет | **−42.3** | −55.8…−28.8 |
| сдвиг: C-нет − A-нет | −17.7 | −26.2…−10.0 |
| сдвиг: C-(G + T) − C-нет | +7.3 | +1.9…+12.3 |
| сдвиг: C-(G + T) − A-нет | −10.4 | −19.6…−1.5 |

- **Успех «нет» по ячейкам без сдвига:** A 80.8, B 61.5, C 38.5, D 51.0, E 37.5, F 35.6, G′ 33.7%.
- Исполнение длинного чанка без новых взглядов теряет больше, чем сам сдвиг. Рефлекс по предмету чинит сдвиг, но не открытое исполнение.
- **R3 по классам:** 1–2 см −22.5, 3–4 см −6.4, 5–6 см −11.0. Разрыв больше всего на малых сдвигах, где частый мозг справляется и сам.

- **Вероятный механизм** (объяснение, отдельно не мерили):
  - При d = 0 вызов T приносит новый чанк сразу. Новый чанк переякоривает G: мозг «видел» сдвиг, U ≈ 0, и G гаснет.
  - Сам мозг сдвиг почти не отрабатывает (раздел 1), то есть T передаёт работу тому, кто её не делает.

**(в) Поисковая строка, не замена R3.** C-G − A-нет (начальные состояния 0–9, n = 260) = −3.5 [−14.6; +6.5], одност. −12.3. Это сравнение выбрано после чтения данных. Оно не прошло бы и порог R3. **R3 остаётся «не прошло».**

## 3. Ложные срабатывания G в контроле

- **Доля.** G включался в 64 из 728 контрольных эпизодов (8.8%), по ячейкам 7–11 из 104.
- **Все 64 — толчки предмета рукой** до первой команды «закрыть»: в парном эпизоде «нет» предмет сдвинулся > 5 мм. По наборам: Object 39, Spatial 23, Goal 2.
- **На этих 64:** G 25.0% против 32.8% у «нет», −7.8 п.п. [−11.3; −3.8]. Несовпадений 1 в пользу G и 6 в пользу «нет».
- **На остальных 664** G не включался и совпадает с «нет» по успеху и длине в 99.8%. Одно расхождение — численный шум.
- **Вклад в R2.** R2 = −0.8 п.п. — это 6 потерянных успехов из 728. Пять из них на ложных срабатываниях (−0.69 п.п.), один — шум (−0.14 п.п.). R2 прошёл с запасом: одност. −1.4 при пороге −2.
- **Для сравнения, в контроле:** T₀ срабатывал в 2.9% (T₀ − нет = −1.5 [−3.7; −0.1]), PPC — в 7.8% (PPC − нет = −1.0 [−3.3; +1.0]).
- **Что это значит.** G доверяет трекеру-оракулу. Когда предмет толкает сама рука, G гонится за ним и мешает захвату. Нужен фильтр контакта — это идея, не проверялась.

## Что это значит для C1

1. **Демо-момент есть.** Геометрический рефлекс, привязанный к предмету, берёт сдвинутую миску заметно чаще во всех ячейках (+11.6 п.п.) и почти не вредит без сдвига. Он работает, потому что не подражает мозгу: C1-E1 показал, что подражать нечему.
2. **Сюжет не «медленный мозг», а «мозг, не замечающий сдвиг».** R4 прошёл, но переспрос бесполезен уже при d = 0. Главный соперник «переспроси сразу» слаб не из-за задержки, а потому что свежий план сдвиг почти не учитывает. Для статьи это честнее и сильнее, но ось задержки из этой сетки не следует. Она этим не опровергнута, а остаётся открытой: проверить её можно только на политике, которая сама отрабатывает сдвиг (T₀ − нет > 0), например на другой VLA.
3. **Выключатель T в нынешнем виде вреден.** Переякоривание после внепланового вызова гасит G в тот момент, когда он нужнее всего. Если T нужен (например, предмет пропал из вида), G не должен гаснуть от чанка, вызванного самим сдвигом. Это идея для следующего спека, не проверялась (G-пост в C не помог).
4. **«Реже думать» упирается в политику.** 50 шагов чанка вслепую стоят ≈ 42 п.п. без всякого сдвига. Рефлекс по предмету это не лечит; нужна поправка по руке или чанки короче.
5. **Ложные срабатывания от толчков** дают 5 из 6 потерянных успехов R2. Нужен фильтр контакта.
6. **Ограничения:**
   - трекер — оракул симулятора;
   - один ступенчатый сдвиг в плоскости стола;
   - 26 задач LIBERO, одна политика;
   - около 2% пар расходятся от численного шума пачки даже без логической разницы: это шум, не смещение.
   - около 1% ступенек (17 из 1681) — по всей видимости, выброс предмета симулятором в момент сдвига (признак — в [записке C1-E3d](e3-detectors.md), «Что дальше», п. 3); без них R1 +11.7 вместо +11.6, R4 +10.9 вместо +10.8 — выводы не меняются (проверено после данных, `scripts/c1_shots.py`).

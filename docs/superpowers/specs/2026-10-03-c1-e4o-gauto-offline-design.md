# C1-E4o: самокалибрующийся рефлекс G-auto — офлайн-выбор варианта, дизайн

*Aleksandr Karpov · 2026-10-03 · Правило выбора записано и запушено до расчёта · Только Мак, старые данные C1-E3 и C1-E4a, без пода · Вариант, выбранный здесь, вписывается в спеку C1-E4 до её данных*

## 1. Зачем

- **G-auto** — рефлекс, который сам выучивает, какую долю сдвига κ мозг несёт в своих планах, без ручной настройки под мозг. Передача та же, что у семейства G в C1-E3 (`src/handoff.py`): с новым планом N рефлекс держит U(t) = (1 − κ_N)·Δ_N + (p(t) − p(t_obs_N)).
  - G: κ ≡ 1. G-keep: κ ≡ 0. G-R: κ̂ по каждому плану (с мёртвой зоной).
  - G-κ₀ — эталон «идеально откалиброванный»: κ₀ из C1-E4a, зафиксирован до данных (π0.5 0.355, SmolVLA 0.038).
- **Вопросы:**
  1. К чему сходится каждая оценка и за сколько сдвигов?
  2. Откуда G-auto берёт обучающие образцы в нашем расписании?
  3. Нужна ли поправка на сдвиг, уже унесённый рукой, и в какой форме?
  4. Окупается ли контекст (рука далеко / близко) и подстройка по промаху?

## 2. Что уже видно (посмотрено до записи этого плана)

- **s = (S·Δ̂)/|Δ|** — доля сдвига, которую к моменту наблюдения плана уже унёс рефлекс. Берётся из поля `S` в `kappa_log` C1-E3. При α > 0 в S входят и синтетические добавки α-мозга (`handoff.py:213–217`).
- **Сырая доля плана на планах с s ≤ 0.1** (r = m/|Δ| по точке захвата, ключ 20; ячейка A, α = 0 / 0.5 / 1): медианы 0.017 / 0.446 / 0.915. При большом s сырая доля следует за s, отсюда смешанные медианы 0.36 / 0.67 / 0.88.
- **При α = 0 и s от 0.1 до 0.9** сырая доля ≈ (0.80–0.86)·s.
- **Эпизоды, где есть хотя бы один план с s ≤ 0.1:** A — 11%, B — 4%, C и F — 0%. С s ≤ 0.2: 18 / 7 / 1 / 1%.
- **Включение рефлекса** — через шаг после сдвига в 99.8% эпизодов. Планы, наблюдённые на этом шаге, имеют s = 0 точно.
- **По ревью:**
  - разброс онлайн-образцов SmolVLA (1.4826·MAD) — около 0.6 на Д1 (α = 0, s ≤ 0.1) против 0.076 на Д2;
  - ĉ при α > 0 падает по разные стороны от 0.9 в зависимости от фильтров;
  - медианы π0.5 по задачам на Д2 — от 0.09 до 0.63.
- **Из сводки C1-E4a:** медианы π0.5 «близко / далеко» — 0.24 / 0.37.

## 3. Данные и варианты

- **Д1 — планы C1-E3** (`results/c1-e3/grid_all.jsonl`). Фильтры:
  - рукава ровно G, GR, Gkeep; вид step, без шума, сдвиг сработал;
  - эпизод не `unstable` и не `pushed_before_fire`;
  - план без запасного пути (`fb` = false);
  - видимый сдвиг близок к истинному: 0.8 ≤ |Δ_N| / mag ≤ 1.25.

  На план: r = m₂₀/|Δ_N|, s, задача, рукав, номер плана в эпизоде. α = 0.5 есть только в A; G-keep в B — только при α = 0.
- **Д2 — сдвиги C1-E4a.** На каждый сработавший сдвиг — запас до закрытия схвата: парный вызов на одном состоянии с одним шумом. π0.5 — 255, SmolVLA — 248. Цель — κ₀, медиана этих же сдвигов.
- **Д3 — пары G / G-keep C1-E3** (только отчёт). Тот же эпизод (задача, начальное, ячейка, α), одинаковый t_fire.
  - κ*_i = m_keep / (m_keep − m_G) по промаху вдоль сдвига при закрытии; годен, если |m_G − m_keep| ≥ 0.25·|Δ|.
  - Оговорка: промах меряется до начала координат предмета (`c1e3_run.py:350`), которое и при хорошем захвате в 3–5 см. Поэтому κ* — эффективная постоянная доля, а не κ̄ законов З1 / З2.
- **Источник образцов:**
  - **И1** — исполняемые планы с s ≤ 0.1, сколько их выпадет, без лишних вызовов. Шум онлайн, поэтому скорость меряется на Д1.
  - **И2** — теневой парный вызов в момент включения рефлекса. Мозг вызывается дважды с одним шумом: на сохранённом наблюдении до сдвига и на текущем (состояние руки на шаг позже).
    - Оба плана выбрасываются, расписание не трогается, +2 вызова на сдвиг в отчёте.
    - Образец = `handoff.target_diff((t_e, x_te, ch_te), (t_fire, x_tf, ch_tf))`·u / |Δ| при Δ = p(t_e) − p(t_fire). Каждая точка захвата привязана к своему наблюдённому положению руки, поэтому шаг руки между наблюдениями не добавляет шума.
    - Это онлайн-версия мерки C1-E4a, поэтому его скорость меряется на Д2.
- **Оценки доли мозга κ̄** (бегущие):
  - **О1** — среднее;
  - **О2** — медиана;
  - **О3** — байес: априорное N(0.5, 0.3²); шум — max(1.4826·MAD накопленных, 0.02), при меньше чем 5 образцах — 0.3; апостериорное среднее.
- **Последовательности для скорости:**
  - 1000 последовательностей длиной 300, сид 0, выборка с возвращением, по кругу задач: в каждом круге задачи в случайном порядке, от каждой — один случайный её образец. Это калибровка, разложенная по всем задачам.
  - Для сравнения (только отчёт) — блоками по задачам: задачи в случайном порядке, все образцы задачи подряд, с перемешиванием.
- **Закон передачи:**
  - **З0** — постоянный κ = κ̄;
  - **З1** — κ_N = s_N + κ̄·(1 − s_N);
  - **З2** — κ_N = ĉ·s_N + κ̄·(1 − s_N).
- **Контекст:** корзины «близко / далеко» по радиусу срабатывания r эпизода (сдвиг срабатывает при расстоянии < r; в Д1 и Д2 одинаково), порог 10 см.
- **Подстройка по промаху (П), только отчёт:** κ̄ ← κ̄ + η_n·sign(κ*_i − κ̄), η_n = 0.2/√n, старт 0.5, на Д3.

## 4. Мерки

- **n90.**
  - Для каждой последовательности n_j — первое n, начиная с которого она держится в ±0.10 от цели до конца (до 300); ∞, если в конце она вне полосы.
  - n90 — 90-й процентиль n_j: наименьшее v, при котором n_j ≤ v у 90% последовательностей. Если это ∞ — «не сходится».
  - Цель — медиана с равным весом задач (вес образца 1 / число образцов его задачи): к ней и идут последовательности по кругу задач.
- **Смещение** — медиана пула минус «истина»:
  - на Д1 истина — α + κ_S (κ_S = 0.038), то есть 0.038 / 0.538 / 1.038; добавка α обрезается, поэтому истина известна примерно, ±0.1 (догадка);
  - для О1 и О3 на Д2 — их значение на всём пуле минус κ₀.
- **Сдвигов до цели:**
  - И1: n90 на пуле Д1 (s ≤ 0.1, α = 0.5, ячейка A) / выход И1 в смеси ячеек C1-E4. Смесь — A и длинные ячейки поровну, выход длинных — среднее C и F.
  - И2: n90 на Д2, по одному образцу на сдвиг.
  - Корзина: n90 в образцах корзины / (доля сдвигов в корзине × выход источника).
- **Точность закона** — только Д1, α = 0 (у α > 0 в s входят синтетические добавки; α > 0 — отчёт).
  - Две половины по задачам: задачи по порядку, чётные / нечётные (список в выводе).
  - На половине подбора: κ̄ — О2 по планам s ≤ 0.1; ĉ — наименьшие квадраты через начало координат, c = Σ s·(r − κ̄(1−s)) / Σ s² по планам с s ∈ [0, 1.1].
  - На другой половине: медиана |κ_N − r| по планам с s ∈ [0, 1.1] и по последнему плану после включения в каждом эпизоде. Последний план берётся по исходному логу; эпизоды, где он отфильтрован, выпадают из этой мерки.
  - Рядом G (1) и G-keep (0). G-R (`k_hat`) — только как ориентир: он читает собственный план.

## 5. Правило выбора (до расчёта)

1. **Закон** (по ошибке на всех планах с s ∈ [0, 1.1], α = 0):
   - **З2**, если ĉ < 0.9 в обеих половинах и ошибка З1 минус ошибка З2 ≥ 0.03. Тогда в C1-E4 ĉ выучивается онлайн для каждого мозга по исполняемым планам.
   - Иначе **З1**, если ошибка З1 ≤ ошибка З0 + 0.03.
   - Иначе **З0**.
2. **Оценка** (по Д2):
   - по умолчанию **О2**;
   - **О3** — если её n90 для π0.5 ≤ 0.75 × n90 О2 и для SmolVLA ≤ n90 О2, а |смещение| ≤ 0.05 у обоих мозгов;
   - **О1** — только если ни О2, ни О3 не сходятся.
3. **Источник.** И1, если для π0.5 сдвигов до цели ≤ 60 (n90 берётся на пуле Д1 α = 0.5, ячейка A, ближайшем к доле π0.5). Иначе И2.
4. **Контекст.**
   - Корзины «близко / далеко» — если на Д2 у π0.5 медианы корзин различаются ≥ 0.10, для корзины «близко» сдвигов до цели ≤ 60, а корзина «далеко» сходится. Иначе одна корзина.
   - Если выбрана О1, корзины считаются по О2.
5. **N** для правила C1-E4 («G-auto после N сдвигов»).
   - N = сдвигов до цели для π0.5 с выбранным вариантом (при корзинах — наибольшее по корзинам), округлённое вверх до 10.
   - Если вариант не сходится за 300 образцов — N = 300, и в C1-E4 это помечается как «G-auto не сошёлся офлайн».
   - **Требование к C1-E4:** калибровочные сдвиги идут по кругу задач, как в последовательностях здесь. Блоками по задачам сходимость медленнее (отчёт).
6. **Только отчёт:**
   - О1;
   - s ≤ 0.2;
   - последовательности блоками по задачам;
   - корзины по типу задачи (если в корзине ≥ 30 образцов);
   - α > 0 в законе;
   - SmolVLA рядом с π0.5;
   - подстройка по промаху (П).

## 6. Чего не делаем

- Успех G-auto здесь не меряем: только точность оценки и закона. Успех — это C1-E4 на поде.
- Подстройку по промаху на π0.5 офлайн не проверяем: пар G / G-keep для π0.5 нет.

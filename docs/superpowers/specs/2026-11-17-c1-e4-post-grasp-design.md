# C1-E4, правило Q7: поправка после захвата — дизайн

*Aleksandr Karpov · 2026-11-17 · Статус: **до данных; прогон после 4 декабря; у владельца — гипотеза H5** · Тип: одна ветка, одно правило (Q7; сквозная нумерация Q дуги C1, следующее после Q6 C1-E3), записанные до кода и до данных · Основа: [спек части 2](2026-10-05-c1-e4-part2-design.md) (§8 «Доводка при переносе», журнал 2026-11-08 «разложение разрыва»), [записка части 2](../../c1/e4-part2.md) («Где теряется успех при d = 20»), [спек клетки R](2026-11-17-c1-e4-delay-trend-design.md)*

**Сокращения.** π — π0.5 `lerobot/pi05_libero_finetuned_v044` @ `8e174154`. LIBERO-MAX, перенос цели, оракул, s = 10, d = 20. **G** — G-auto (закон З1, κ̄ = 0.306). **G+** — G-auto с поправкой после захвата (метка ветки `GautoPG`). **c_X** — успех среди эпизодов ветки X с захватом после события (`grasp_ok`), как в журнале части 2 от 2026-11-08.

## 1. Зачем и что мотивирует

- Измерение `addac2f` (записка части 2): при d = 20 разрыв Base − G = 26.7 п.п., из них 16.4 [11.0; 21.9] теряется после захвата. c_Base = 66.0, c_G = 32.9.
- Механизм виден в коде. Рефлекс выключается на первой команде «закрыть»: у G — `src/objreflex.py` `act`, у G-auto — `HAgent.act` в `src/handoff.py`, в обоих `if not self.grasp_started`. Действия π — приращения положения руки, а накопленная добавка рефлекса остаётся в положении руки. Дальше рука исполняет планы, наблюдённые до захвата, и несёт предмет по их пути, сдвинутому на эту добавку. Свежий план, наблюдённый после захвата, при d = 20 приходит не раньше чем через 20 шагов.
- **Эти числа гипотезу мотивируют, но не доказывают.** Они получены на тех же 300 случаях, где гипотеза возникла, и разложение — измерение без правила.
- **Две прошлые попытки той же идеи не прошли, это пишется прямо:**
  - C1-E3, Q6a: возврат добавки после подъёма на SmolVLA, d ≤ 20 — 0.0 [−1.1; +1.2], не прошло;
  - часть 2, §8: `GautoU` (снимать добавку только перед отпусканием, которое командует устаревший план) — офлайн по трём трассам закон не сработал ни разу: «открыть» командует уже свежий план, а промах ставится раньше, при касании стола, под устаревшим планом (в 2 эпизодах из 3 ошибка совпала со смещением рефлекса: 23° / 1.50, 7.5° / 1.18). Идея на будущее оттуда: снимать поправку под устаревшими планами до касания стола. G+ ниже — она.

## 2. Ветка G+ — вариант Б (выбран до кода)

**Два варианта, выбран Б.**
- **А — держать руку** (нулевые приращения положения, схват закрыт) до прихода первого плана, наблюдённого на шаге ≥ t_close. Свежий план сам планирует от фактического положения руки с предметом.
- **Б — сдвиг остатка дозахватного плана** на разницу «где план собирался взять» минус «где реально взяли».
- **Почему Б.** А при d = 20 стоит 20–29 шагов простоя на каждый эпизод с захватом. Эпизоды G при d = 20 и так длинные, а у LIBERO есть предел шагов. Б не останавливает руку и бьёт ровно в найденный механизм: путь устаревшего плана после захвата. Вариант А — только запасной: переход на него — запись в журнал до кода.

**Б, точное определение.** Всё до первой «закрыть» — как у G, бит в бит по коду. После первой «закрыть» (t_c), пока не исполнена первая команда «открыть»:
- для исполняемого плана N с наблюдением t_obs,N:
  - если t_obs,N < t_c (дозахватный план): цель поправки U_N = p̂_N − x(t_c). Здесь x(t_c) — положение схвата на шаге t_c, p̂_N = x(t_obs,N) + G_POS · Σ clip(a_k)[:3] по действиям плана N до его собственной первой «закрыть» (`grasp_point` из `src/objreflex.py`). Если в плане N нет «закрыть», U_N = 0;
  - если t_obs,N ≥ t_c (план видел руку с предметом): U_N = 0;
- поправка шага — машинерия `_g` без изменений: e = k_p · (U_N − (c − c(t_obs,N))), предел |e| ≤ |U_N| / T_ramp (при U_N = 0 — предел по накопленному с t_obs,N), мёртвая зона EPS = 5 мм, clip ±1, накопление c.
- Так для свежего плана поправка возвращает руку на его собственный путь, если с его наблюдения рука успела сдвинуться. Поправка не ходит по кругу с периодом s + d (ошибка первой версии `GautoU`, §8 части 2): цель у каждого плана задана относительно его же наблюдения и не зависит от того, что исполнялось раньше.
- После первой «открыть» поправки нет.
- Только оракул, только π.

## 3. Правило Q7 (записано до кода и до данных)

- **Данные:** новые эпизоды, не те, на которых гипотеза возникла. Это 640 случаев `evalrest`, d = 20. G и G+ в одном процессе на одном Base (`--base-prefix`, срезанный по событию; G+ полного Base не требует). Записи G клетки R20 сюда не берутся: другой процесс и другие пачки (режим С).
- **Величина:** Δc = c_{G+} − c_G, п.п.; c — отношение сумм (захваты с успехом / захваты).
- **Интервал:** перцентильный бутстрэп по кластерам исходной задачи, 2000 пересборок, `default_rng(0)`, одна матрица кластеров на обе ветки (как в `scripts/c1e4_grasp_split.py`). Пересборка без захвата в ветке оставляет c неопределённым; полоса по определённым, их число в отчёте.
- **Правило:** Δc ≥ +10 и нижняя граница 95% (перцентиль 2.5) > TOL → «поправка после захвата поднимает долю доведённых захватов при d = 20». Иначе → «не показано». Границы сырые, TOL = 1e-9.
- **Подпись величины** — как в записке части 2: «успех среди эпизодов с захватом после события». Успехи без `grasp_ok` идут отдельно (r).

## 4. Рядом, только отчёт

- g, s, r обеих веток с числами эпизодов; s_{G+} − s_G парно по случаю с 95%.
- **Захват может измениться:** G+ действует после «закрыть», а `grasp_ok` считается по подъёму ≥ 3 см после события, то есть тоже после «закрыть». Поэтому печатается, у скольких случаев `grasp_ok` различается между G и G+, и Δc на случаях, где захват есть у обеих веток.
- Доля шагов после «закрыть» с ненулевой поправкой; |U_N| у первого дозахватного плана и рядом E_N = C(t_c) − C(t_obs,N) — добавка рефлекса, которой план N не знает (оценка `GautoU`); угол и отношение |U_N| / |E_N|; число эпизодов, где «открыть» пришло раньше свежего плана.
- Разложение разрыва Base − G+ по формуле журнала части 2 (нужен Base той же клетки — только отчёт, если Base полный; иначе не печатается).

## 5. Мощность (до данных, грубо)

- На 300 случаях при d = 20 у G 149 захватов, 95% c_G — [23.2; 44.3]: ошибка ≈ 5.4. На 640 (≈ 318 захватов) ≈ 3.7 на ветку.
- Ошибка Δc — между 3.7 (сильная положительная связь веток на одних случаях) и 5.2 (независимость). Возьмём ≈ 4.5.
- Правило требует **и** точку ≥ +10, **и** нижнюю > 0. Если истинный эффект ровно +10, первое условие выполняется примерно в половине прогонов: мощность ≈ 50%. При истинном +14 ≈ 80%. Порог +10 — треть разрыва c (66.0 − 32.9 = 33 п.п.).

**Tech:** Python 3.12, numpy; `~/Desktop/M2R-c1-env/bin/python`; pytest.

**Timing constraint:** pod C runs the controls `cgrid` until ≈ 03:30 UTC. Nothing may be pulled on the pod while it runs: bash reads `gpu_c1e4m.sh` as it goes, and `cgrid` reads `c1e4c_summary.py` per line. Push to c1-e4 freely; pull only after `cgrid` ends.

## Task A — the regulator, the runner, tests

**Files:**
- Create `src/vservo.py` and `tests/test_vservo.py`.
- Modify `scripts/c1e4m_run.py` (additions only) and `tests/test_c1e4m_run.py` (additions only).

- [ ] **`PBVSAgent(gauto.GAgent)`.**
  - Method labels `PBVS<λ>` with λ ∈ {0.1, 0.3, 1.0}.
  - Constructor arguments: `band = {"model": "I"|"A"|"I*"|"A*", "G": [gx, gy], "B": [bx, by], "delta": δ}`.
  - It inherits the conveyor schedule, the engagement `t_e` (HAgent.observe), `x_hist`, `p_hist` and the first-close stop.
  - `on_new_chunk`: anchor t_a = the current step (the last observed t), x(t_a), Δx(t_a−1) = x(t_a) − x(t_a−1) (0 at t = 0), and the chunk's start index t_a − t_obs.
  - `act(t, a)`, when `t_e` is not None and t ≥ t_e and not grasp_started:
    - the path w(t) on xy from the anchor with model M over the plan's clipped rows j = t_a … t−1. The integrator: Σ G·clip(a_j). ARX: Δ_j = G·clip(a_j) + B·Δ_{j−1}, starting from Δx(t_a−1);
    - e = (x(t) − w(t)) − (p(t) − p(t_obs)) on xy;
    - if |e| ≤ δ: unchanged; else a_xy = clip(clip(a_plan,xy) − λ·e / G_POS, ±1);
    - z, rotation and gripper untouched; no ramp, no κ, no E.
  - Log counters: steps acting, steps in the window, Σ|e|, max|e|, sign flips of e·û (û = the direction of p(t_e) − p(t_obs) at engagement).
- [ ] **`gauto.parse_arm` must accept `PBVS*`** without changing behaviour for existing labels. The preferred way is a small wrapper in vservo used by the runner's make_agent. Do not edit `GAgent.METHODS`.
- [ ] **Runner.**
  - `make_agent` builds `PBVSAgent` for `PBVS*` arms, from `--band <json>`. The band goes into `conf["pbvs"]` only when a PBVS arm runs.
  - `--log-traj`: a Base record gets `traj = {"x": xs (round 1e-6), "p": objs, "a": acts[:, :3]}`. `plans_in` is already there.
  - Records of PBVS arms get `pbvs = {counters}`.
  - Base-only runs (`--arms ''`) stay allowed without `--base-prefix`.
- [ ] **Tests (spec §9, items 1-8):**
  - the identity at λ = 1 with an exact integrator arm;
  - a still object gives no correction;
  - the dead band;
  - the window (before t_e, after close);
  - the axes;
  - anchor (b) at d > 0;
  - the ARX recursion;
  - no regression: all existing C1-E4 tests unchanged and green;
  - act_hash of Base equal with and without `--log-traj` (fake brain / env as the existing runner tests do).

- [ ] **`--band R/V0_*.jsonl` → `band.json`** (spec §3):
  - candidates I, A (scouting coefficients), I*, A* (least squares per axis on steps before the first close; 2-fold by the set's order; δ out of fold; final coefficients on all of V0);

  - δ_M = the ⌈0.95·n⌉-th order statistic from below (60 → the 4th largest);
